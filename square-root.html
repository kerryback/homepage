    Why it works: if the root so far is a and the next digit is x, the new root is 10a + x, and (10a + x)² = 100a² + (20a + x)·x. The 100a² is already subtracted, so each round only has to take away (20a + x)·x — which is why you double the root, tack a digit on the end, and multiply by that same digit.
